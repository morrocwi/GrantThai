# forms/

**Phase 0 stub.** Human-direct, per-tab Markdown forms (general, project,
workplan, utilization, attachments), editable in any text editor. They
compile to the same `project.yaml` as every other editor, through
`grantthai import-form forms/` or a double-click launcher (both v0.1).

The five tab names and their order follow one observed form
(`mappings/nriis/section_to_tab.yaml`) and are `NEEDS_VERIFICATION` until
confirmed from a public call or TOR document.

Ships: v0.1. See the repository root README.md and GRANTTHAI_STANDALONE.md
for the full system description, and docs/design/PLAN.md for the
design plan this scaffold follows (where they differ, spec/ wins).
